<h2> 개요 </h2>
2D 그래픽, 시점은 탑 뷰로 진행되며 방치형 RPG와 타워 디펜스를 섞은 혼합형 RPG 입니다. <br>

<h2> Windows 빌드 </h2>
bin 폴더 -> Windows 빌드 ( <b>Tower Defence RPG 2D.exe</b> ) <br>
<h2> Android 빌드 </h2>
추후 apk 파일 추가 예정
<h2> 게임 상세 설명</h2>
1. 키 입력 : Esc (게임 일시정지) <br>
2. 구글 로그인 <b>불가</b> / 게스트 로그인 / 이메일 로그인 <b>택 1</b> <em>(추후 게스트 -> 이메일 연동 가능)</em> <br>
3. 이메일 로그인 시 <b>이메일 형식</b> 맞춰야 <b>회원 가입</b> 가능 <em>(ex : asd@asd.com)</em> <br>
4. 게임 플레이 화면 : 우측 하단 화살표 버튼 누르면 유저의 현재 스탯, 던전과 같은 기능 활성화/비활성화(SetActive)
